# 🚀 JavaScript Array Methods Project

A beginner-friendly JavaScript project that demonstrates the most commonly used **Array Methods** through an interactive web application.

Users can create an array dynamically and perform different array operations using buttons.

---

## 📌 Project Overview

This project helps beginners understand how JavaScript Array Methods work by providing a simple graphical interface.

Users can:

- Create an array
- Insert elements
- Perform different array operations
- View results instantly
